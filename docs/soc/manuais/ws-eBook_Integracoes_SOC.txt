1. Objetivo
Este documento visa apresentar as integrações disponibilizadas pelo SOC –
Software Integrado de Gestão Ocupacional, que permitem a comunicação
automática com outros sistemas de mercado. Além disso, também são
apresentadas as soluções desenvolvidas por Empresas Parceiras, que
permitem integrar as informações com seus respectivos sistemas.

2. Conceito – Integração
A integração é uma solução que visa automatizar a sincronização das
informações contidas em diferentes sistemas. Esta solução possibilita, por
exemplo, integrar um software de Folha de Pagamento com o SOC, para
que as informações dos Funcionários e de seus Atestados estejam sempre
atualizadas e correspondentes.
2.1. Web Service
Web Service é uma tecnologia que permite, através do envio e recebimento
de informações, por meio de arquivos no formato XML, a integração entre
diferentes sistemas, independentemente de suas plataformas. Ou seja, a
partir de uma solicitação enviada pelo sistema externo, as informações da
mesma serão registradas no SOC.
Isso significa que qualquer sistema poderá se comunicar com o SOC, desde
que utilize os padrões especificados na Documentação Técnica.
Cada Web Service possui um objetivo específico quanto às informações a
serem integradas. Temos um serviço para o cadastro de Funcionários, outro
para cadastro de EPIs, outro para Resultado de Exames, e assim por diante.

1. O Sistema Externo envia os dados para a interface de integração. Por
exemplo, um sistema de folha envia os dados de um funcionário para a
interface.
2. A interface adequa os dados para o formato de requisição recebido pelo
SOC e realiza o envio.
3. O SOC processa a requisição e responde quanto ao sucesso da mesma.
Confira, no tópico “3.1 Web Services”, quais são os serviços disponibilizados
atualmente pelo SOC.

2.2. SFTP
O SFTP é um método de transferência de arquivos entre sistemas remotos,
por meio de uma conexão protegida, onde os arquivos serão enviados ou
consumidos de forma segura e criptografada.
Essa solução permite, por exemplo, que os arquivos gerados e vinculados
ao SOCGED, bem como os arquivo incluídos diretamente no GED (via
upload), sejam enviados para o diretório informado pelo cliente. Essa
solução pode ser utilizada, por exemplo, para que os arquivos gerados no
Portal eSocial, e armazenados no SOCGED, sejam enviados diretamente
para um servidor configurado.

A solução SFTP também possibilita, por exemplo, que os arquivos gerados
no Portal eSocial sejam armazenados em um SFTP do SOC para que, por
meio de login e senha fornecidos, possam ser consumidos por um sistema
externo.

3. Integrações Padrão SOC
Abaixo estão listadas as integrações disponíveis no layout padrão do SOC,
por meio de Web Services ou SFTP. Estas integrações, além de gratuitas,
estão prontas para serem utilizadas, bastando que a interface seja
desenvolvida do lado do software que será integrado, com base nas
documentações técnicas disponibilizadas pelo SOC.
Com o intuito de identificar as integrações que possuem relação com dados
a serem enviados ao eSocial, as mesmas estão sinalizadas com um ícone no
canto superior direito.
Junto a cada integração listada, está disponível um esquema que representa
o fluxo da informação e possíveis ações que podem ser realizadas por meio
da interface. Para mais detalhes técnicos sobre o funcionamento da
integração, utilize os QR Codes para acessar as suas respectivas
documentações. Para isso, leia-os por meio da câmera de um smartphone,
ou clique no próprio QR Code, caso esteja visualizando a versão digital
deste eBook.

3.4. Integrações eSocial
Por meio das integrações disponíveis no SOC é possível tornar mais
eficiente a inclusão e a extração das informações necessárias para atender
ao eSocial. As soluções Interface específica com outros Sistemas
(Integração de Dados) e Portal eSOCial (Integração de Arquivos)
permitem que as informações a serem enviadas para o eSocial sejam
integradas com sistemas externos, como os de RH, ERP e Folha.
Integração de Dados: Os dados existentes no SOC são disponibilizados
para que o sistema do cliente consuma, consolide, transmita e controle os
leiautes para o eSOCial. Como essa solução não realiza a geração dos
arquivos no SOC, não é possível utilizar o Web Service Resposta eSocial
para o preenchimento do recibo de resposta do eSocial.
Integração de Arquivos: Os arquivos XML são gerados pelo SOC, no
formato a ser recebido pela plataforma do governo. Dessa forma, os
sistemas integrados poderão buscar os arquivos prontos e realizar o envio
para o eSocial. Esta solução permite o controle do retorno dos envios, por
meio do Web Service Resposta eSocial, possibilitando o preenchimento do
recibo retornado pelo eSocial.

3.4.1 Preenchimento dos Dados no SOC para o eSocial
Por meio dos Web Services disponíveis no SOC, sinalizados com o ícone
“eSocial” no tópico “Integrações Padrão SOC”, é possível integrar
informações para que sejam enviadas para a plataforma do governo. Por
exemplo: os cadastros de funcionários do sistema de folha podem ser
integrados ao SOC, para que estejam sempre atualizados.
Na imagem abaixo, pode ser visualizada a relação dos Web Services com
cada layout do eSocial. Estão sinalizados os serviços que impactam em
algum dado nos respectivos layouts. Dessa forma, é possível visualizar
todos os Web Services que podem ser utilizados para preenchimento de
acordo com cada layout.

3.4.2 Extração dos Dados para o eSocial
Entre as Soluções eSOCial disponíveis, as duas primeiras (1 - Interface
específica com outros Sistemas e 2 - Portal eSOCial) permitem configurar
integrações para a exportação das informações contidas no SOC.
O SOC possibilita a exportação de dados do eSocial de duas formas:
3.4.2.1 Integração de Dados - Interface específica com outros Sistemas

Essa solução permite que os dados exigidos pelo eSOCial sejam
consumidos para serem integrados aos Sistemas de Folha de
Pagamento/RH.
Os dados solicitados serão disponibilizados através da ferramenta Exporta
Dados, para que os Clientes SOC (diretos ou indiretos) desenvolvam
interfaces com o software e integrem essas informações com sistemas de
Folha de Pagamento/RH, que serão os responsáveis por reproduzir e
transmitir os layouts ao Governo Federal. Nesta solução, os dados
existentes no SOC são disponibilizados sem que estejam no layout dos
eSocial, para que sejam consumidos, consolidados e transmitidos. Como
essa solução não realiza a geração dos arquivos no Portal, não é possível
utilizar o Web Service Resposta eSocial para o controle dos arquivos
processados pela plataforma do governo.
Para realizar a integração dessa solução, deve ser utilizado o Web Service
Exporta Dados, descrito no item 3.1.22. Exporta Dados. Este serviço
possibilitará a utilização dos Relatórios Exporta Dados em integrações com
outros sistemas, de modo a possibilitar que os mesmos consumam os dados
contidos no SOC.

Integração de Dados (Interface Específica com Outros Sistemas)
Essa solução permite que os dados de Saúde e Segurança Ocupacional

Os dados solicitados serão disponibilizados através da ferramenta Exporta
Dados, para que os Clientes SOC (diretos ou indiretos) desenvolvam
interfaces com o software e integrem essas informações com sistemas de
Folha de Pagamento/RH, que serão os responsáveis por reproduzir e
transmitir os leiautes ao Governo Federal.

3.4.2.2 Integração de Arquivos - Portal eSOCial

Essa solução permite criar e gerenciar os arquivos XML no
formato do eSocial, com base nas informações preenchidas
no SOC. A integração nessa solução tem como fim a
transmissão destes arquivos para os sistemas de
RH/Mensageria, que realizarão o envio à plataforma do governo.
Por meio das integrações disponíveis, é possível automatizar o download
dos arquivos gerados, de modo a viabilizar a extração destes arquivos pelo
sistema externo, além de permitir o preenchimento do recibo retornado pela
plataforma do governo, possibilitando um maior controle do envio das
informações. Para isso, se faz necessária a utilização dos Web Services de
Download de Arquivos SOCGED, que permite o download dos arquivos XML
gerados no Portal eSOCial e o de Resposta eSocial, que permite informar o
recibo retornado pela plataforma do governo, possibilitando o controle das
informações enviadas.
Outra possibilidade é a alocação desses arquivos, já no formato do eSocial,
em um SFTP do SOC ou do próprio cliente, para que possam ser acessados
pelo sistema do cliente, que realizará o envio do arquivo à plataforma do
governo. Essas soluções podem ser visualizadas nos tópicos SFTP e
Instruções para Implementação SFTP.
No quadro a seguir, é ilustrada a utilização dessa solução de forma
automatizada por meio dos Web Services disponíveis.

4.8. Instruções para Implementação
As soluções desenvolvidas por Parceiros, citadas acima, utilizam os Web
Services disponibilizados pelo SOC. Sendo assim, os procedimentos a serem
realizados no SOC são os mesmos das Instruções de Implementação dos
Web Services Padrão SOC, descritas no tópico 3.3.1.
Para cada integração listada, estão especificados, no campo “Web Services
Utilizados”, os Web Services necessários para o funcionamento da mesma.
Além das configurações a serem realizadas no SOC, também se faz
necessário o contato com a empresa parceira, por meio do contato técnico
descrito, para que possam ser realizadas as demais configurações.
Observação: As integrações dos parceiros SinergyRH e Senior utilizam o
módulo de Integração com Parceiros do SOC, que torna a implementação
da integração mais rápida e fácil. Para mais detalhes, pode ser consultado o
item “Integração com Sistemas Parceiros” do nosso Manual.
